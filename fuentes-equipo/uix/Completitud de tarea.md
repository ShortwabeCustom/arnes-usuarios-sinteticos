# Completitud de tarea: cómo interpretar la tasa de éxito

La tasa de éxito es el porcentaje de participantes que completan una tarea. Estos rangos son **orientativos**; el promedio de referencia es **78%**.

## Interpretación por rango

| Tasa de éxito | Interpretación |
|---|---|
| 100% | Muy alta. Esperable en tareas críticas o con usuarios expertos |
| 90-99% | Alta |
| 80-89% | Por encima del promedio |
| 78% | Promedio de referencia |
| 67-77% | Por debajo del promedio |
| < 67% | Señal de problemas importantes de efectividad |
| < 50% | Problema considerable de usabilidad |

## Semáforo para decidir qué hacer

| Nivel | Tasa de éxito | Acción |
|---|---|---|
| 🟢 Verde | ≥ 90% | Objetivo cumplido |
| 🟡 Amarillo | 78-89% | Revisar oportunidades de mejora |
| 🟠 Naranja | 50-77% | Problema de efectividad |
| 🔴 Rojo | < 50% | Problema crítico de usabilidad |
